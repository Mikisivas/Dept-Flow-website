Routes

/admin/whitelist · /admin/rollover Never commit blind

Whitelist upload and level rollover

Two bulk operations, both irreversible in practice, both gated behind a diff you have to read. The programme is parsed from each matric prefix, so a wrong prefix is a validation error rather than a silent miscategorisation.

Rollover · confirming, then complete

Notes

  • Rollover is the only action in the product that asks you to type the session to confirm. It is irreversible in practice, and the confirm button stays disabled until the text matches.
  • The 40 unresolved Level 400 students are broken out as held back rather than folded into the promoted count, because rolling over hides them — they stop appearing in any current-session list.
  • Rejected CSV rows name the row number and the actual fix, so the file can be corrected without guessing.
  • A claimed whitelist row is never overwritten — otherwise a re-upload could silently orphan a live account.

Routes

/admin/disputes · /admin/students

Registration disputes and student management

Both actions here are soft: revoke freezes an account and frees the matric number, deactivate disables login and retires the number. Neither deletes a single attendance record.

/admin/config · /admin/payments · /admin/timetable · /admin/courses

Configuration, payments, timetable and courses

Configuration holds the geo-fence editor, which is the one admin screen that can silently break attendance for a whole hall — so each venue states its radius in metres and when it was last checked.

Route

/admin/audit admin · read-only

Audit log

Every reason field in the other twenty-five screens ends up here. No edit, no delete, not even for an admin — the log is the reason the authority actions can be trusted.

Carried through the whole system

  • Admin never sees a named student in academic trouble. No at-risk list, no attendance percentages — those live in the HOD's routes. This role gets counts, queues and transactions.
  • Nothing is ever deleted. Revoke freezes and unclaims; deactivate disables login and retires the matric number. Attendance history survives both.
  • The geo-fence editor plots the fence, never a student. Coordinates are checked, kept 30 days as a pass-or-fail, and shown to nobody.
  • Six groups, forty-one routes. Every orange surface carries black text at 9.30:1, provisional is dashed with no fill everywhere it appears, and no state is signalled by colour alone.
