Notes

  • Filled checkpoint cells on this screen take a #C96E10 border, because a bare #FF9935 cell disappears against the #FFF4E8 panel.
  • The rejected counter is not decoration — five rejections outside the hall in one class is what a proxy attempt looks like from the lectern.
  • The cancel button in the one-checkpoint dialog is "Call checkpoint 2", not "Cancel" — it names the thing they probably meant to do.
  • Live counters carry aria-live="polite" so the count is announced without interrupting.

Notes

  • The lecturer sees counts below 75%, never a named at-risk list — pastoral follow-up is the HOD's scope, and duplicating it here blurs the separation.
  • Cancelling removes the session from the denominator, so the dialog says nobody is penalised. Without that sentence lecturers avoid cancelling and hold empty classes.
  • "Enter paper register" appears only where digital capture was missing or partial — never as a standing shortcut.
  • Flagged rows are tinted and carry a labelled badge, so the flag survives a greyscale print of the register.
